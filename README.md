# Rally

취미·스포츠 커뮤니티와 운동 기록을 한 앱에서 — 운동 캘린더·통계, 소셜 매칭, 친구, 커뮤니티까지. (Android)

## 다운로드

최신 APK는 **[Releases](https://github.com/tystarme/rally-app/releases/latest)** 에서 받을 수 있어요.

- 현재 버전: **v1.8.1**
- 설치할 때 기기에서 *"출처를 알 수 없는 앱 설치 허용"* 이 필요할 수 있어요.

## 업데이트 내역

### v1.8.1
- 운동 기록 화면의 상단 버튼이 너무 많아 제목이 잘리던 문제를 고쳤어요. 프리셋과 설정은 오른쪽 위 ⋮ 메뉴로 옮겼어요.

### v1.8.0
- 쉬는 시간 알림이 종소리로 바뀌었어요. 10초 전에 한 번, 3초 전에 두 번, 끝나면 세 번 울려요.
- 무음/진동 모드에서도 진동은 확실히 와요. 이때 소리는 이어폰을 연결했을 때만 이어폰으로 나가고 스피커로는 울리지 않아요. 소리를 켜둔 상태에서는 평소처럼 스피커로 울려요.
- 운동 추가 팝업에서 세트를 체크해도 쉬는 시간이 끝나면 "다음 운동 완료"로 이어져요.
- 운동을 하나만 기록해도 하루 타임라인 바가 보여요.
- 오운완 내보내기의 타임라인에 하루 흐름을 보여주는 가로 바가 추가됐어요.
- 하루 기록을 통째로 다른 날짜에 복사할 수 있어요 (완료 체크는 초기화돼요).
- 하루의 운동을 골라서 한 번에 프리셋에 추가할 수 있어요.
- 기록 추가 화면의 저장 버튼이 화면 아래 버튼에 가리지 않아요.
- 1RM 통계의 기간 버튼이 화면 안에 다 들어와요.

### v1.7.1
- 친구 요청·댓글·모임 채팅·모임 참여를 앱이 꺼져 있어도 알림으로 받아요.
- 알림을 탭하면 해당 글이나 채팅방으로 바로 이동해요.
- 설정 > 알림에서 종류별로 켜고 끌 수 있어요.
- ⚠️ 앱 ID가 정식 출시용으로 바뀌어, 이번 버전은 기존 앱을 지우고 새로 설치해야 해요. 설정에서 "운동 기록 계정에 저장"을 켜두셨다면 로그인 시 기록이 복원됩니다.

### v1.7.0
- 쉬는 시간이 끝나면 '다음 운동 완료'로 다음 세트를 바로 체크할 수 있어요.
- 휴식 알림이 시간이 다 되면 깔끔하게 사라져요.
- 한 세트만 한 운동도 타임라인에 표시돼요.

### v1.6.0
- 친구가 공개하면 친구의 운동 기록과 프로필을 볼 수 있어요.
- 1RM 통계에 기간 선택(최근 1주·1달·전체·기간 지정)과 추이 그래프가 생겼어요.
- 앱을 업데이트하면 새로워진 점을 바로 알려드려요.

### v1.5.0
- 쉬는 시간이 끝나기 10초·3초 전에 미리 알림을 보내드려요.

### v1.4.1
- 이메일 발송 한도를 넘었을 때 안내 문구를 더 친절하게 바꿨어요.

### v1.4.0
- 운동 타임라인 레일과 쉬는 시간 타이머를 다듬었어요.
- 하루 운동 순서를 직접 편집할 수 있어요.
- 1RM·통계 계산을 실사용 기준으로 개선했어요.

### v1.3.0
- 통계를 개편했어요: 운동시간 재정의, 예상 1RM, 알짜 칼로리 평균.

### v1.2.0
- 일별 운동 편집, 커스텀 종목 병합, 루틴 프리셋 기록을 추가했어요.

### v1.1.0
- 쉬는 시간 타이머가 백그라운드에서도 알림으로 동작해요.

### v1.0.1
- 이메일 인증 코드(OTP)로 안전하게 가입할 수 있어요.

### v1.0.0
- Rally 프리릴리스를 시작해요. 운동 기록·통계·매칭·커뮤니티를 만나보세요.
